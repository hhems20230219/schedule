火警出動人員車輛分配表 v27

【本版主要修正】
1. 新增 true / false 本地與線上資料切換。
2. 車輛只能拖到「車輛」欄。
3. 人員只能拖到人員欄、休息、因公外出。
4. 修正舊版主表「破壞小組」部分儲存格誤設成 vehicle 的問題。
5. 還原舊 boardState 時也會驗證型別，錯誤的車輛/人員配置不會再載入。
6. 所有 JS / HTML / CSS / GAS 主要段落都有維護註解。
7. JSON 標準本身不能寫註解，因此 JSON 欄位說明集中在本 README。

============================================================
一、本地 / 線上資料切換
============================================================
修改 data/board-data.json：

  "dataSource": {
    "useLocalData": true
  }

true：
- 使用瀏覽器 localStorage
- 不讀、不寫 Google Apps Script
- 不做遠端輪詢
- 適合本機開發 / 測試

false：
- 使用 Google Apps Script Web App + Google Sheet
- GitHub Pages 讀寫同一份線上 boardState
- 其他人開啟網頁看到最後即時資料
- 會依 pollIntervalMs 定時讀最新資料

重要：線上模式 useLocalData=false 時，如果 gasWebAppUrl 沒設定，系統會直接顯示錯誤，不會偷偷改用 localStorage。

============================================================
二、線上 GAS URL
============================================================
data/board-data.json：

  "api": {
    "gasWebAppUrl": "你的 GAS Web App URL",
    "pollIntervalMs": 10000,
    "requestTimeoutMs": 15000
  }

正式 GitHub Pages 建議：
- useLocalData = false
- gasWebAppUrl = 正式部署 URL

============================================================
三、拖曳規則
============================================================
HTML 每個可放置格使用 data-kind 決定資料型別：

  data-kind="vehicle"  → 只能放車輛
  data-kind="person"   → 只能放人員

例如：
- 11車、12車、91車、92車只能放在「車輛」欄。
- 不能放到帶隊官、駕駛員、瞄子手、副瞄子手、搜救小組、攝影照相、破壞小組。
- 人員也不能放進車輛欄。
- 休息與因公外出只接受人員。

程式有三層防護：
1. Sortable group 分流。
2. onMove 即時判斷 item type 與 target kind。
3. restoreBoardState 載入舊資料時再次驗證。

============================================================
四、資料流程
============================================================
第一次沒有任何 boardState：
- 看板全白。

匯入勤務 Excel：
- 解析番號 / 姓名 / 身分。
- 解析備勤91 / 備勤救災。
- 套用目前時段。
- 匯入完成後立即自動保存。

人工拖曳：
- 放開滑鼠 / 手指後立即自動保存。
- 不需要儲存按鈕。

updatedAt    最後更新時間

不拆 Personnel / DutySchedule / BoardState 多張工作表。
